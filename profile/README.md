## How we publish

1. **GitHub** … 各ツールのリポジトリ／Release（正本）
2. **BOOTH** … ミラーや有料版: [unagitech.booth.pm](https://unagitech.booth.pm/)
3. **Ko-fi** … 任意の応援・投げ銭: [ko-fi.com/unagitech](https://ko-fi.com/unagitech)
4. Company site / blog / Note … 案内。zip は置かない

When a tool is mirrored elsewhere, **GitHub is updated first**.
